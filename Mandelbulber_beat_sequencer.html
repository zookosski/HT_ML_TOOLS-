Displace vs Replace

      
    
        
  • Displace (default) — formula adds to the parameter's existing slider value. Off=0 / On=0.5 means "leave it alone, then briefly add 0.5 on each lit step." Keeps all your manually-tuned setup intact.
    • 
        
  • Replace — formula sets the parameter outright, ignoring the slider. Use only when you want the script to be the sole source of truth for that parameter.
    • 
        
  • The most common "no action" surprise: using Replace mode with values far from where the slider was. The camera teleports out of frame and you see nothing. Switch to Displace.
    • 
      

    

    

      
Release · numeric type · per-row copy

      
    
        
  • Release is measured in steps. 0.25 = razor transient (one frame snap), 4 = pad-like glide that smears across a quarter-bar. The frame-equivalent shows live below the slider.
    • 
        
  • Type: Float (default), Integer (rounds inputs), Unsigned (clamps output ≥ 0 inside the formula — important for iteration counts, bailouts, etc.)
    • 
        
  • Each row has its own copy button — grab one formula at a time and paste into the right Mandelbulber field
    • 
        
  • For audio reactivity: switch to Displace, set On value to 'audio_amplitude'… actually that won't work since On is a number field. Use the LFO tool with audio influence for that.
